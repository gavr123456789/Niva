# Фаза 6. Отделить declarations от entry execution

[← Индекс плана](clojure-repl.md)

Generated namespace'ы должны быть безопасны для повторной загрузки. Поэтому
произвольные top-level expressions entry-файла нельзя оставлять на верхнем
уровне `.clj`.

Их нужно компилировать в отдельную функцию, например:

```clojure
(defn __niva_entry! []
  ...)
```

Семантика watch mode:

- при первом запуске `__niva_entry!` вызывается один раз;
- обычный reload обновляет её Var, но не вызывает функцию;
- повторный запуск возможен отдельной командой `:restart`/`--restart`, если она
  будет добавлена позднее;
- lifecycle hooks не должны автоматически выводиться из произвольного Niva
  кода.

Это предотвращает повторную печать, запись файлов и повторный старт серверов
при каждом сохранении.
